HyakAnimeTournament

HyakAnimeTournament est un prototype personnel et non officiel de tournois et championnats d'anime.

Cette page présente uniquement la configuration Google OAuth utilisée par Rclone pour sauvegarder les données chiffrées du prototype sur le Google Drive personnel de son propriétaire.

Le prototype et son code source ne sont pas distribués sur ce site.
